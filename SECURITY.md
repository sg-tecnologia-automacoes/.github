# Security

Found a security problem in one of our repositories or apps? Please do not open a public issue.
Send a private message to a maintainer on GitHub (@joshsegatt or @goncalvesdev) with what you found and how to reproduce it. We answer within a few days.

Encontrou um problema de segurança? Não abra issue pública: mande mensagem privada para um mantenedor no GitHub (@joshsegatt ou @goncalvesdev) com o que encontrou e como reproduzir.
